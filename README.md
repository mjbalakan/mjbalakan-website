# mjbalakan.com

Personal research website of Mohammad Javadi (MJ) Balakan, hosted on GitHub Pages.

## Updating
1. Edit `data/site.json` (bio, highlights, news, career, profiles, citation stats) or `data/papers.json` (publications).
2. Run `python3 build.py` (no dependencies). It regenerates `index.html`, `papers/*.html`, `sitemap.xml`, `robots.txt` and `404.html`.
3. Commit and push. GitHub Pages republishes within a minute or two.

Figures live in `img/`, the CV in `files/MJBalakan_CV.pdf`.
